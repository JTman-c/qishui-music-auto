# 汽水音乐自动看广告

> 手机连着电脑放着广告，脚本自动帮你点「领奖 / 领取成功」，循环攒**免费听歌时长**和**无损音质天数**。
>
> 只点界面上真实存在的按钮，**不改 App、不加速、不伪造观看进度**，广告该播多久还是多久。

改编自原项目 [cvabm/qishui](https://github.com/cvabm/qishui)。

## ✅ 它能做什么

- 自动循环：领奖 → 等广告播完 → 关闭广告 → 进入下一轮
- 看广告攒免费听歌时长
- 看广告领无损音质天数（**2 个广告换 1 天**）
- 不小心被带进直播间时，自动识别并点 × 退回

## 📦 准备工作（一次性）

1. 电脑安装 **Python 3.10～3.12**，安装时务必勾选 **Add Python to PATH**
2. 电脑安装 **ADB（platform-tools）**，并加入系统 PATH
3. 手机打开 **开发者选项 → USB 调试**，用数据线连上电脑
4. 在电脑命令行执行 `adb devices`，能看到设备编号就说明连接成功

## 🚀 怎么用

1. 在项目文件夹里安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. 手机打开汽水音乐，进入看广告页面，**保持亮屏、不要锁屏**
3. 双击 **`启动.bat`** 启动脚本
4. 想停止时，在脚本窗口按 `Ctrl + C`

## 🧭 脚本是怎么点的

一轮广告的固定流程：

1. 弹出奖励弹窗 → 点绿色 **「领取奖励」**
2. 广告播放，顶部出现「xx 秒后可领取奖励」→ 等着，不乱点
3. 倒计时结束 → 点右上角 **「领取成功 ×」** 关闭广告
4. 回到第 1 步，继续下一轮

额外处理：

- 出现「xx 秒后进入直播间」会先点 **取消**，不被自动带进直播间
- 万一已经进了直播间，识别到评论框「说点什么」等特征词，会自动点右上角 × 退出
- 按钮文字严格匹配，不会把广告里的「拆盲盒领奖励」误当成领奖按钮点进去

## 🎧 无损音质怎么领

播放页点歌名旁边的音质标签 → 顶部横幅点 **「免费升级 / 继续领」** → 之后和普通广告一样自动跑即可。

> 全景声、录音室音质仍然需要 SVIP，广告只能换到 **无损音质**。

## ⚙️ 常用设置（`qishui_auto.py` 顶部）

| 设置项 | 作用 |
|---|---|
| `REWARD_TARGETS` | 领奖按钮文字，如「领取奖励」「继续观看」 |
| `CLOSE_TARGETS` | 广告结束页的「领取成功 ×」和退出面板的「退出不看了」 |
| `CONTINUE_TARGETS` | 无损入口 / 结算按钮：「继续领 / 免费升级 / 领取第」 |
| `ENABLE_SKIP` | 是否自动点「跳过」；提前跳过可能拿不到奖励，谨慎开启 |
| `POLL_INTERVAL` | 每轮检查的间隔时间 |
| `CLICK_COOLDOWN` | 点击后冷却，防止连点 |
| `TARGET_ROI` | 各按钮允许点击的区域，用来防误点 |

## ❓ 常见问题

- **截图失败 / 一直显示等待中** → 检查 `adb devices` 是否在线、手机有没有锁屏
- **一直不点按钮** → App 升级后按钮文字变了，改 `REWARD_TARGETS`
- **点错位置** → 看 `debug_clicks/` 里保存的标注截图，再调整 `TARGET_ROI`

## 📌 说明

- 实测适配汽水音乐 `21.8.0`；不同版本按钮文案可能有变化，失效时改脚本顶部配置区即可。
- 本项目仅用于学习交流，使用时请遵守汽水音乐的用户协议。
